# DOMO для Home Assistant

Балансы и расход по всем лицевым счетам из приложения [DOMO](https://domo.uz) (Hududgaz): газ, электричество, вода, вывоз мусора, «Mening uyim» и другие услуги.

Интеграция неофициальная и не связана с DOMO или Hududgaz.

## Как происходит вход

Пароля в DOMO нет. Вы вводите номер телефона, зарегистрированный в приложении, и DOMO присылает SMS-код. Код вводится один раз, дальше интеграция сама поддерживает вход:

- Токен доступа живёт 7 дней. Интеграция обновляет его за сутки до истечения.
- Токен обновления живёт 365 дней. Каждое обновление продлевает его, поэтому пока Home Assistant работает, сессия не заканчивается.
- Если DOMO всё же завершит сессию, Home Assistant покажет уведомление о повторной авторизации. Подтвердите его, и придёт новый SMS-код.

В списке активных сеансов приложения Home Assistant виден как **Home Assistant**. Вход на телефоне при этом сохраняется.

## Установка

### HACS

1. HACS → ⋮ → **Пользовательские репозитории** → добавьте `https://github.com/dilshodm/ha-domo`, категория **Integration**.
2. Установите **DOMO** и перезапустите Home Assistant.

### Вручную

Скопируйте `custom_components/domo` в папку `config/custom_components` и перезапустите Home Assistant.

### Настройка

**Настройки → Устройства и службы → Добавить интеграцию → DOMO**. Введите номер телефона, затем код из SMS.

## Сущности

Каждый лицевой счёт становится устройством с названием по услуге и номеру счёта, например «Газ 1007090145». В поле модели устройства указано название или адрес дома.

| Сенсор | Счета | Примечание |
|---|---|---|
| Баланс | все | UZS, как показывает DOMO (положительный = переплата) |
| Показание счётчика | газ, электричество | м³ / кВт·ч, `total_increasing`, подходит для панели «Энергия» |
| Дата показания | со счётчиком | время последнего показания |
| Расход за месяц | газ, электричество | м³ / кВт·ч |
| Начислено за месяц | счета с аналитикой DOMO | UZS; атрибут `previous_month` |
| Расход / начислено за последний день | газ, электричество | последний день из суточной статистики DOMO; атрибут `date` |
| Обновлено | все | диагностика: когда DOMO последний раз синхронизировал счёт |

Сам вход тоже отображается устройством (**DOMO +998…**) с кнопкой **Обновить данные**. Она просит DOMO заново синхронизировать все счета с поставщиками (как обновление свайпом в приложении) и сразу забирает результат, не дожидаясь следующего опроса. После успешного обновления кнопку можно нажать снова через минуту.

### Новые счета

Если добавить услугу или дом в приложении DOMO, новые устройства и сенсоры появятся в Home Assistant при следующем опросе. Чтобы увидеть их сразу, нажмите **Обновить данные**. Если счёт удалён в DOMO, его сенсоры станут недоступны, а устройство можно удалить на его странице.

## Параметры

**Настройки → Устройства и службы → DOMO → Настроить**:

- **Интервал опроса**: от 1 до 24 часов, по умолчанию 3. Сам DOMO обновляет расход примерно раз в сутки.
- **Язык**: Русский, Oʻzbekcha или English. Определяет язык ответов DOMO и названия устройств («Газ / Gaz / Gas 1007090145»). Его также спрашивают при первоначальной настройке, по умолчанию берётся язык Home Assistant. Названия сенсоров, как обычно, следуют языку самого Home Assistant.

## Конфиденциальность

Номер телефона и токены DOMO хранятся только в записи конфигурации Home Assistant. Они используются для запросов к `domo-gw.uz` и больше никуда не отправляются.
